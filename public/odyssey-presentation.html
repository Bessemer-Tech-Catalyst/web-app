Intelligent Failure Classification

Every failure is classified into one of 4 categories with 90%+ confidence:

🐛 App Defect

Genuine bug in the application. File report, notify team.

🔧 Script Drift

Locator broke, but app works. Route to automatic healing.

⚡ Flake

Transient failure (network timeout, race). Retry automatically.

📝 Plan Error

Test scenario doesn't match reality. Send back to planner.

Result: Zero false positives. Real bugs surface with evidence.
